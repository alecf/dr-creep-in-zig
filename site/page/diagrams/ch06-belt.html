Each slat is one cell. Its pixels are code 10 and never change; what changes is its screen-plane byte: dark grey ($B) for code 01, and white ($1), light grey ($F) or grey ($C) for code 10. Every other step each cell takes the shade its right-hand neighbour had, and the stripes slide left.
